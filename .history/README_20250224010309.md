# ZORA: AI-Powered Learning Platform for Bhutanese Students

## Project Overview

ZORA is an AI-powered learning platform designed to improve the education experience for Bhutanese students. Specifically tailored for Class 10 and 12 students studying Geography and History, ZORA aims to bridge the gap between traditional study methods and modern, digital learning by providing structured, interactive, and personalized study resources. The platform integrates an AI chatbot that offers curriculum-aligned answers, personalized learning paths, and AI-generated quizzes and courses to reinforce key concepts.

## Installation

To run the ZORA project locally, follow the steps below.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (version 16.0 or later)
- [Yarn](https://yarnpkg.com/) (optional, can use npm)
- [Git](https://git-scm.com/)

### Steps

1. **Clone the repository**:

   ```bash
   git clone https://github.com/your-username/zora.git
   cd zora
   ```

2. **Install dependencies**:

   Using npm:

   ```bash
   npm install
   ```

   Or using Yarn:

   ```bash
   yarn install
   ```

3. **Run the development server**:

   Using npm:

   ```bash
   npm run dev
   ```

   Using Yarn:

   ```bash
   yarn dev
   ```

   Using other package managers:

   ```bash
   pnpm dev
   ```

4. **Open in browser**:

   Once the server is running, open your browser and navigate to:

   ```
   http://localhost:3000
   ```

## Running Tests

## About ZORA

### Project Background

Education in Bhutan faces challenges in providing students with accessible and curriculum-aligned study materials. The vast amount of uncurated content available online often does not align with the Bhutanese syllabus, leaving students confused and with unresolved academic doubts. Traditional classroom learning, while structured, does not always cater to individual learning needs, and students often hesitate to ask questions due to imposter syndrome.

ZORA aims to solve these problems by providing a personalized, AI-driven learning platform. The platform's chatbot assists Class 10 and 12 students studying Geography and History, offering instant explanations, handling general queries through the Gemini API, and providing interactive courses and quizzes. By leveraging AI, ZORA makes learning more efficient and engaging for students.

### Problem Statement

Students in Bhutan often struggle to find curriculum-aligned study materials, and traditional education does not always cater to individual needs. ZORA seeks to address these challenges by offering an AI-powered platform with personalized study resources for Geography and History students in Class 10 and 12, while also providing quizzes and courses designed to enhance their understanding.

### Aim and Goal

- **Aim**: To develop an AI-powered learning platform that enhances learning for students in Bhutan.
- **Goal**: To bridge the gap between traditional study methods and digital learning by making education more accessible and engaging for Bhutanese students.

### Objectives

- Fine-tune AI models with the Gemini API for curriculum alignment
- Develop interactive AI-generated courses and quizzes
- Implement a personalized AI chatbot to assist students with specific learning needs

### Scope

#### System Scope:

- AI chatbot for real-time assistance with curriculum-aligned queries
- Interactive study materials like quizzes and courses
- Personalized learning paths based on assessments

#### User Scope:

- Available to all students with a special focus on Class 10 and 12 students studying Geography and History
- General knowledge assistance is available to all users

## Requirements

### Functional Requirements

#### Admin Module:

- Admins can manage user accounts (add, suspend, delete)

#### User Module:

- Students can register and log in to access study materials and chat with the AI
- Students can attempt quizzes and access AI-generated courses
- Personalized learning paths are provided based on student progress

### Non-Functional Requirements

- **Reliability**: The platform should offer consistent performance with minimal downtime
- **Security**: User data must be securely stored and encrypted
- **Scalability**: The platform should handle an increasing number of users without degrading performance
- **Maintainability**: The system should feature modular, easy-to-maintain code

## Tech Stack

- **Frontend**: Next.js, TailwindCSS
- **Backend**: JavaScript
- **Database**: PostgreSQL
- **Cloud**: Supabase
- **Version Control**: Git, GitHub

## Literature Review

The integration of AI in education has proven to enhance personalized learning. ZORA incorporates these principles by offering AI-driven quizzes and courses aligned with Bhutan's curriculum. The platform's chatbot, fine-tuned with the Google Gemini API, ensures that students receive relevant and accurate answers.

## Ethical Considerations

The deployment of AI in education raises ethical concerns such as data privacy, algorithmic bias, and accessibility. ZORA adheres to best practices in AI ethics to ensure fairness, transparency, and reliability in its learning content.

## Future Improvements

While ZORA offers curriculum-aligned content for Class 10 and 12 Geography and History, future developments will include expanding the subject coverage, improving the AI's accuracy, and ensuring broader access to students, especially in rural areas.
